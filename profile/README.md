# FTEF: Federated Trust Evidence Framework

Trust between domains is earned by evidence, leased in time, and cut by events. One contract for every partner.

FTEF is an open specification for how a relying party evaluates, records and acts on the security posture of a
federation partner in another domain, on the basis of evidence. **Status: 0.1 pre-draft.**

| Repository | What |
|---|---|
| [spec](https://github.com/ftef-spec/spec) | the specification, schemas and examples (Community Specification License 1.0; schemas and code Apache-2.0) |

Schemas are served at `https://ftef.vdhome.be/schema/`. Contributions: DCO sign-off and the Community Specification
Contributor License Agreement; see each repository's `CONTRIBUTING.md`. Security reports: private vulnerability
reporting in the affected repository.
