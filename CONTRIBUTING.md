# Contributing to FTEF repositories

Each repository has its own `CONTRIBUTING.md`, which takes precedence over this default. Everywhere:

- Every commit carries a DCO sign-off (`git commit -s`, https://developercertificate.org/).
- Specification repositories also require the Community Specification Contributor License Agreement, which you accept by contributing.
- Open an issue before changing anything normative.
- Use fictional parties on `.example` domains in examples. Never include real infrastructure, risk registers, attack paths or personal data.
- AI-assisted contributions are welcome if you have reviewed them, take responsibility for them, and can sign off truthfully. Disclose the help with an `Assisted-by:` or `Co-Authored-By:` trailer. Only a person signs off.
